## 🚀 Game Features Built by Gemini

1. **360° Orbital Arena & Singularity Physics:**
   - Rings of destructible orbital shields wrap around a central black hole gravity well.
   - Holding `Space` or `Left-Click` activates the Singularity pull to curve ball trajectories around the core.
2. **Procedural Web Audio Synthesizer:**
   - Uses the browser's native Web Audio API to produce dynamic bass drone waves, crisp paddle impacts, and rising pentatonic musical chimes that match active combo streaks.
3. **Power-Ups & Relic Drops:**
   - Includes real-time power-ups such as Laser Pierce, Multi-Ball Split, Overdrive Shield, and Time Slowdown.
4. **Game Modes:**
   - Instant toggle between high-intensity Arcade Mode and relaxing Zen Mode.
